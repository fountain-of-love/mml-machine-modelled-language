# Experiment 3.4 — Compositional Generalization

**Status:** structurally held-out synthetic development experiment  
**Operation:** zero-shot identification from pairwise-constructed semantic state  
**Primary claim:** a 20-dimensional semantic representation generated from four latent variables can be executed against complete target signatures absent from construction

## Why This Experiment Exists

Experiments 3.1–3.3 establish local consistency for direct intersection, governed legal qualification, and cross-level semantic transition. Their fixtures were authored alongside their probes. They do not establish held-out combinatorial generalization.

Experiment 3.4 asks the stronger question:

> Can MML execute a projected 20-dimensional semantic representation against complete combinations that never occurred during construction, using only lower-order relationships compiled from other combinations?

This directly tests the next protocol boundary behind the [Combinatorial Scaling Proposition](../proposition.md). It is not yet a scaling result, because the 20 semantic dimensions are generated from four latent variables and the realized complete-signature universe contains only 256 signatures.

## Strict Holdout Boundary

Merely withholding a query string is insufficient when the target node and all its trait edges already exist in compiled state. In that design, symbolic conjunction can recover the target through lookup.

Experiment 3.4 therefore separates three artifacts:

1. **Projected coordinate basis:** 20 semantic families with four values each, generated from four latent base variables.
2. **Construction state:** aggregate coordinate-pair counts derived from 192 training entities; entity identities and complete signatures are discarded.
3. **Evaluation registry:** 64 disjoint held-out entities whose complete signatures never enter construction.

The compiled state stores relations of arity two only. Held-out target signatures are evaluation-side records used to test zero-shot identification.

## Semantic Families

The fixture covers:

```text
animal            habitat           diet
size              behaviour         colour
geography         time              social_structure
locomotion        climate           activity
reproduction      migration         lifespan
body_covering     altitude          water_dependency
nesting           defense
```

Every family has four governed values. At query width `k`, the possible query space is:

```text
4^k
```

At `k=20`, the full signature space contains:

```text
4^20 = 1,099,511,627,776
```

The synthetic generator uses four latent base-four coordinates and declared modular coefficient rows. This creates a 20-dimensional projected representation with learnable lower-order structure while keeping every complete signature explicit and leakage-auditable. The theoretical coordinate product is large, but the generator realizes only the 256 latent tuples.

## Construction And Test Split

All `4^4 = 256` latent tuples are partitioned before execution:

```text
training: sum(latent digits) mod 4 != 0  -> 192 entities
testing:  sum(latent digits) mod 4 == 0  ->  64 entities
```

Construction counts coordinate pairs within training entities, then discards the training identities and complete signatures. Test signatures are disjoint by construction and checked again by an executable leakage audit.

This is **structural holdout**, not independent authorship. The generator, split, implementation, and evaluation remain project-authored.

## Query Protocol

For every held-out target, execute prefixes at:

```text
k = 1, 2, 3, ..., 20
```

The family order is frozen in the probe artifact. Each query contains the target's value for the first `k` families in that order. The target must be identified among all 64 held-out signatures.

No test query or target signature contributes to pair counts, graph edges, embeddings, policy selection, or parameter tuning.

## Treatments

| Treatment | Contract |
| --- | --- |
| Flat keyword retrieval | Rank by explicit query-coordinate overlap with each held-out signature |
| Embedding centroid | Frozen rank-16 SVD embedding of the training pair-count matrix; cosine between query and candidate centroids |
| Vector composition | Cosine over explicitly composed multi-hot query and candidate vectors |
| KG traversal | Add independently propagated Personalized PageRank fields, then score candidate signatures |
| Symbolic conjunction | Retain candidates containing every explicit query coordinate |
| MML | Independently propagate coordinate fields, combine them by geometric-mean soft intersection, then score unseen signatures |

All treatments receive the same held-out registry. The local embedding is deterministic and constructed solely from training pair counts. It is not a claim about a named external embedding model; adding one is a required follow-up.

## Measurements

For each treatment and every `k`, report:

- deterministic top-1 accuracy;
- tie-adjusted accuracy;
- mean reciprocal rank;
- mean target rank;
- mean target margin;
- mean target tie count;
- possible query combinations `4^k`; and
- possible full signatures `4^20`.

The machine artifact preserves every target, query, top candidate, rank, tie count, margin, and reciprocal-rank contribution.

## Leakage And Integrity Controls

The experiment must fail if:

- any complete test signature occurs in training;
- a held-out identity, serialized signature, or signature hash appears in the construction fixture;
- compiled relation arity exceeds two;
- construction retains entity identities or complete signatures;
- a declared family or width is missing;
- a treatment does not execute for every target and width; or
- checked-in machine and human artifacts drift from a fresh run.

## Interpretation Contract

A positive execution result is genuinely stronger than local authored intersection because the compiled state never contains the target combinations. Its precise claim, however, is narrower: MML can execute a 20-dimensional representation generated from four latent variables without seeing complete target signatures. To support a distinctive MML scaling claim, MML must add value beyond exact overlap, explicit vectors, symbolic conjunction, and additive graph traversal. If those controls match the curve, the fixture demonstrates projected-fixture identifiability rather than a soft-intersection advantage.

It would not yet establish:

- independent or real-world compositional generalization;
- generalization to natural-language descriptions;
- robustness to noisy, missing, or contradictory attributes;
- superiority over a named production embedding model;
- useful accuracy across arbitrary coordinate bases; or
- a net construction, governance, or execution-cost advantage.

Those remain separate experiments. The result report must preserve this boundary even if MML achieves perfect accuracy at large `k`.
