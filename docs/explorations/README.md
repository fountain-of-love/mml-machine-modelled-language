# Downstream Explorations

These explorations investigate what could be built on top of executable MML and a future SOS architecture. They are intentionally separated from the runnable evidence.

- [Semantic Seed Vault](seed-vault/README.md) explores a human-readable CML-shaped knowledge base through a five-domain scientific grammar.

The Seed Vault is not evidence that MML or SOS works. It is a larger research proposal showing one possible destination if explicit semantic representation, execution, persistence, and governance prove useful.
