# Semantic Seed Vault

This folder preserves scientific and architectural semantic seeds. Its top-level structure now follows the three-element lens:

- **form**: structures, identities, substrates, and boundaries;
- **movement**: transformations, relations, flows, resonance, and capacity;
- **direction**: orientation, purpose, governance, and vector of development.

Its name is inspired by the [Svalbard Global Seed Vault](https://www.seedvault.no/), which preserves biological seeds so diversity can be regenerated in the future.

The current body of work belongs under **movement**. It defines a higher-level conceptual relation across five physical domains: the **RCL — Resonant Capacity Law**. The RCL package is curated under [movement/discovery/RCL](movement/discovery/RCL/README.md), where its claims, evidence, proof materials, and research extensions have an explicit authority structure.

The vault is also a foundation for **Machine Modelled Language (MML)**. Its concepts, semantic roles, equations, constraints, provenance, and failure conditions provide governed scientific structure that a Common Language Model can make addressable. MML can then compile selected structure into mathematical weights and task-specific operators, allowing scientific knowledge to participate directly in deterministic mathematical operations.

The present proof is deliberately analytical and equation-led, establishing a clear admitted model class before a machine-verifiable implementation or wider empirical programme is introduced. Its universality is bounded by that class; experimental replication and stronger empirical claims are well-defined extensions rather than prerequisites for the present analytical result.

For the scientific claim, scope, maturity, and novelty boundary, start with the [RCL Claim Ledger](movement/discovery/RCL/00-governance/Claim-Ledger.md) and continue with the [Five-Domain Analytical Derivation](movement/discovery/RCL/02-proof/Resonant-Capacity-R3-Certificates.md).

For the broader **Semantic Operating System (SOS)** architecture, see [../What.md](../../sos/Architecture.md). For dual persistence, see [../Dual-Persistence.md](../../sos/Dual-Persistence.md). For participation, competing assertions, provenance, and rollback expectations, see [../Commons-Governance.md](../../sos/Commons-Governance.md).

## Architectural Role

- **CML** is the **Common Language Model** under development: the shared schema defining concepts, relations, evidence, constraints, maturity, and topology.
- **Seed Vault** is this knowledge base: the durable content organized according to CML.
- **MML** supplies the executable semantic mechanism that makes this larger CML-shaped knowledge base addressable and reusable by machines.
- **LLMs** assist discovery and expression, but candidate knowledge must be validated before deposit.

The vault can preserve established knowledge, competing interpretations, negative results, counterexamples, open questions, and imputed candidates without presenting them as equally mature.
