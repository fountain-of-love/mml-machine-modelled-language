# Inventory

## Identity

- Canonical label: `inventory`
- Local id: `form.inventory`
- Status: `candidate`

## Definition

Inventory is a structured collection of candidate or accepted items assembled for scope definition, discovery, comparison, or review before or alongside stricter ledger governance.

## Boundary

Included:

- structured candidate collection
- discovery surface
- scope-setting list
- review-oriented item set

Excluded:

- a fully governed maturity ledger by default
- a single concept considered in isolation
- an unstructured corpus dump
- a final ontology merely because it is large
