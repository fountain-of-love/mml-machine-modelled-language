# Seed

## Identity

- Canonical label: `seed`
- Local id: `form.seed`
- Status: `candidate`

## Definition

Seed is a minimal initiating semantic unit from which broader structure, classification, relation, or governance can later grow.

## Boundary

Included:

- starting semantic unit
- generative nucleus for later growth
- bounded initial deposit
- reusable origin point for further elaboration

Excluded:

- the whole mature ontology
- a random note with no developmental role
- a final proof or compiled structure
- a surface token treated as a seed without boundary review

## Aliases

- semantic seed
- initial seed
- seed unit
