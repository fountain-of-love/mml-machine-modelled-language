# Ledger

## Identity

- Canonical label: `ledger`
- Local id: `form.ledger`
- Status: `candidate`

## Definition

Ledger is a governed record surface that tracks the status, maturity, scope, and review state of a bounded semantic set over time.

## Boundary

Included:

- governed record surface
- auditable list of admitted or tracked items
- explicit maturity tracking
- scope-bounded review structure

Excluded:

- a loose inventory with no acceptance discipline
- a single concept seed file
- an informal note with no governance role
- a relation itself rather than the record that tracks it

## Aliases

- governance ledger
- record ledger
- tracked ledger

## Provenance

- Seed Vault governance usage
- RCL claim and concern ledger practice
