# Concept Seeds

This folder stores concept seed documents in the same branch structure described by [[Seed Tree]].

Use the narrowest folder that matches the seed's current role. If a folder grows too broad, split the folder and update [[Seed Tree]] before adding more loose files.

## Folder Tree

| Folder | Role |
| --- | --- |
| `root-orientation/` | Central orientation concepts such as [[Concept]], [[Semantic Hub]], and [[Semantic Neighborhood]] |
| `form-primitives/` | Foundational Seed Vault form concepts such as [[Boundary]], [[Capacity]], and [[Direction]] |
| `vault-governance/` | Concepts that govern collection, validation, source handling, and relation representation |
| `navigation-grammar/` | Concepts that govern Obsidian traversal and link quality |
| `process-grammar/` | Concepts that make process structure graph-ready |
| `relation-predicates/` | Relation predicates expressed as active concept pages |
| `computing-domain/` | First science-and-technology domain expansion under computing |

## Growth Rule

Add new seeds to a branch folder, not the root of `seeds/`, unless the seed is a temporary placement decision that will be resolved immediately.
