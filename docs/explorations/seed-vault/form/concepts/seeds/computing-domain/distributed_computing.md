# Distributed Computing

## Definition

Distributed computing is the computing paradigm in which several interconnected computational processes or systems cooperate through message exchange or coordination mechanisms to perform work that is not confined to a single node.

## Boundary

Included:

- multi-node computation
- message-based coordination
- distributed execution
- system-spanning computational work

Excluded:

- a computer network considered only as infrastructure
- parallelism confined to one machine without distribution boundary
- generic cloud branding with no architectural meaning
- organizational distribution unrelated to computation
