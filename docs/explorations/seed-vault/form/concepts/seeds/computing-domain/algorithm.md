# Algorithm

## Identity

- Canonical label: `algorithm`
- Local id: `form.algorithm`
- Status: `candidate`

## Definition

Algorithm is a finite, governed procedure for transforming input, state, or problem conditions into a determinate class of outputs through ordered computational steps.

## Boundary

Included:

- stepwise computational procedure
- explicit transformation method
- finite rule-governed process
- reusable procedural pattern

Excluded:

- any informal heuristic with no step boundary
- a full software system as such
- raw data structure without operative procedure
- computation in general without a declared method

## Aliases

- computational procedure
- stepwise method
- algorithmic process
