## Definition

Computer network is a connected system of computational nodes and communication links through which data, control, and service interactions are transmitted under defined protocols and boundaries.

## Boundary

Included:

- connected computing nodes
- communication pathways
- protocol-governed data exchange
- networked service interaction

Excluded:

- networking as a field of work
- a single computer in isolation
- telecommunications in every non-computing sense
- abstract topology without a networked system context
