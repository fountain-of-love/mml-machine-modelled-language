# Data Structure

## Identity

- Canonical label: `data_structure`
- Local id: `form.data_structure`
- Status: `candidate`

## Definition

Data structure is a particular organized form for storing, arranging, and accessing data so that computational procedures can operate on it under declared constraints.

## Boundary

Included:

- structured data organization
- representation shape for access and update
- computational storage arrangement
- form that conditions algorithmic behavior

Excluded:

- data considered without organization
- database management system as a whole
- an abstract algorithm with no representational structure
- semantic concept identity outside computational representation
