# Operating System

## Identity

- Canonical label: `operating_system`
- Local id: `form.operating_system`
- Status: `candidate`

## Definition

Operating system is the foundational software system that manages hardware resources, execution processes, memory, files, access control, and system-level coordination for computational work.

## Boundary

Included:

- system resource management
- process and memory coordination
- file and device control
- core execution environment for software

Excluded:

- application software as such
- computer hardware by itself
- every infrastructure platform regardless of operating role
- virtualization or hypervisor layers unless explicitly modeled
