# Database Management System

## Identity

- Canonical label: `database_management_system`
- Local id: `form.database_management_system`
- Status: `candidate`

## Definition

Database management system is the software system that defines, stores, queries, updates, secures, and administers structured data collections as operational databases.

## Boundary

Included:

- database control software
- query and update management
- storage administration
- transactional or managed data access

Excluded:

- database as a data collection considered apart from management software
- generic data structure without system administration
- information system as a whole
- every data-processing tool regardless of persistent storage role
