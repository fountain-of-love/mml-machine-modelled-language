# Evidence

Evidence supports claims but does not define their current status. Current scientific maturity is recorded in the [Claim Ledger](../00-governance/Claim-Ledger.md), and concern disposition is recorded in the [Concern Ledger](../00-governance/Concern-Ledger.md).

## Evidence classes

- `literature-review/` — reproducible novelty and prior-art review, especially C10;
- `discovery-corpus/` — equation inventories, analogue mappings, negative mappings, and coding records;
- historical evidence intakes — currently preserved in [Papers Overview Legacy](../99-archive/Papers-Overview-Legacy.md) until extracted into focused records.

## Rule

An evidence record may recommend a claim update, but only the governance ledgers can make that update authoritative.
